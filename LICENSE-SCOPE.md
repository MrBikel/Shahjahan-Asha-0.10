# Font Software scope / Font Software-এর আওতা

## বাংলা

`LICENSE.txt`-এর SIL Open Font License 1.1 (OFL-1.1) কেবল নিচে তালিকাভুক্ত Font Software-এর ক্ষেত্রে প্রযোজ্য:

| Font Software ফাইল | বিবরণ |
|---|---|
| `ShahjahanAsha-0.10.ttf`, `ShahjahanAsha-0.10.sfd` | প্রকাশিত ফন্ট ও সম্পাদনাযোগ্য FontForge source |
| `ShahjahanAsha-opentype-features-0.10.fea` | OpenType layout source |
| `sources/svg/`, `sources/masks/` | glyph vector outline ও mask source |
| `OWNER-CONFIRMED-CELLS-0.10.csv`, `TRACE-DETAILS-0.10.csv`, `SOURCE-MAP-MERGED-PROVISIONAL.csv` | Font Software-এর source maps ও glyph assignments |
| `FEATURE-ASSIGNMENT-NOTES-0.10.txt` | feature implementation notes |
| `scripts/build_from_sfd.py`, `tests/validate_release.py` | build ও validation scripts |

এই Font Software-এ কোনো Reserved Font Name নেই। `LICENSE.txt`-এর সম্পূর্ণ ইংরেজি পাঠই OFL-এর প্রামাণ্য পাঠ; এখানে দেওয়া বাংলা বিবরণ আইনি অনুবাদ নয়।

`source photo` থেকে নেওয়া চারটি crop `sources/confirmed-crops/`-এ পরীক্ষা ও নথির প্রমাণ হিসেবে রাখা হয়েছে; সেগুলো Font Software-এর অংশ নয় এবং OFL-এ লাইসেন্স করা হচ্ছে না। একইভাবে `README.md`, এই scope notice, `TEST-REPORT-0.10.txt`, `RELEASE-MANIFEST.txt`, `proofs/`, এবং `docs/`—এর লেখক-প্রোফাইল ও প্রতিকৃতিও Font Software নয় এবং এই প্রকল্পের মাধ্যমে OFL-এ লাইসেন্স করা হচ্ছে না। প্রতিকৃতিটি লেখক-প্রোফাইল ও প্রকল্প-নথিতে ব্যবহারের অনুমোদন নিয়ে অন্তর্ভুক্ত; এর পুনঃব্যবহারের কোনো সাধারণ downstream অনুমতি OFL থেকে পাওয়া যায় না। অন্য নথি ও ছবির ক্ষেত্রে তাদের নিজ নিজ অধিকার প্রযোজ্য; OFL ছাড়া অতিরিক্ত লাইসেন্স এখানে দেওয়া হচ্ছে না।
